# AudioFormatBar v0.1.2

将应用改为纯菜单栏运行模式。

## 更新

- 运行时不显示 Dock 图标。
- 运行时不显示在应用切换器中。
- 保留菜单栏图标和 Glass 风格弹窗。
- 保留 Applications 和 DMG 安装方式。
- 保留应用图标、开机自启开关、VOX 适配和播放器元数据接口。

## 系统要求

- macOS 26 或更高版本。
- Apple Silicon 和 Intel Mac 通用二进制。
- 当前构建使用 ad-hoc 签名，未进行 Apple Developer ID 公证。
- 首次打开如果被 Gatekeeper 阻止，请右键应用并选择“打开”。
