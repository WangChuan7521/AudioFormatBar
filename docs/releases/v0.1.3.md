# AudioFormatBar v0.1.3

降低空闲状态下的 CPU 占用。

## 更新

- 将 CoreAudio 全量扫描的兜底周期从 1 秒调整为 5 秒。
- 为兜底定时器加入容差，减少系统唤醒频率。
- 当设备信息没有变化时，不再重复发布 UI 更新。
- 当音源信息没有变化时，不再重复触发 SwiftUI 重绘。
- 降低玻璃弹窗在后台空闲时的布局和渲染开销。
- 保留实时手动刷新、VOX 适配、播放器元数据接口和开机自启。

## 实测

在 macOS 26.6.2、Apple Silicon 环境下连续采样：

- 空闲 CPU 通常为 `0.0%`
- 周期刷新瞬时值约为 `0.3%–0.4%`
- 不再持续维持在 `2%–4%`

## 系统要求

- macOS 26 或更高版本。
- Apple Silicon 和 Intel Mac 通用二进制。
- 当前构建使用 ad-hoc 签名，未进行 Apple Developer ID 公证。
