# AudioFormatBar v0.1.1

修正安装和应用显示问题，并加入开机自启。

## 更新

- 新增应用图标。
- 新增标准 DMG 安装镜像，包含 Applications 快捷方式。
- 应用现在作为普通 macOS App 显示在 Applications、启动台和 Dock。
- 菜单栏弹窗新增“开机自启”开关。
- 开机自启使用 `SMAppService.mainApp`。
- 当系统要求用户批准登录项时，可直接打开系统设置。
- 保留 VOX 适配和自研播放器元数据接口。

## 安装

1. 下载并打开 `AudioFormatBar-v0.1.1-macOS-universal.dmg`。
2. 将 `AudioFormatBar.app` 拖入 `Applications`。
3. 从 Applications 启动应用。
4. 打开菜单栏弹窗，按需开启“开机自启”。

## 系统要求

- macOS 26 或更高版本。
- Apple Silicon 和 Intel Mac 通用二进制。
- 当前构建使用 ad-hoc 签名，未进行 Apple Developer ID 公证。
- 首次打开如果被 Gatekeeper 阻止，请右键应用并选择“打开”。
