# AudioFormatBar v0.1.0

首个公开测试版本。

## 功能

- macOS 26 原生菜单栏 App 和 Glass 风格弹窗。
- 枚举 CoreAudio 输出设备，显示采样率、物理位深、声道和传输类型。
- 识别 Hog Mode 及正在独占 DAC 的进程。
- 使用 CoreAudio Process Object API 识别活跃输出进程。
- 自动跟随优先级：独占设备 → 活跃设备 → 系统默认设备。
- 支持手动固定输出设备。
- 多输出流设备可展开查看各输出流的格式。
- VOX 当前曲目适配。
- 解析 FLAC、ALAC、WAV/AIFF 和 DSF 的本地音源格式。
- 自研播放器可通过本机 UNIX Domain Socket 发送 v1 JSON Lines 元数据。
- 自动在 VOX 和自研播放器元数据之间切换。

## 系统要求

- macOS 26 或更高版本。
- Apple Silicon 和 Intel Mac 通用二进制。
- 当前构建使用 ad-hoc 签名，未进行 Apple Developer ID 公证。
- 首次打开如果被 Gatekeeper 阻止，请右键应用并选择“打开”。

## 说明

界面显示的是 DAC 当前物理输出格式，不等同于音源文件的真实位深。实际输出可能受系统混音器、音量、播放器 DSP 和设备容器格式影响。
